### Weekly time allocation (~35 hours/week)

**Search (40% — ~14 hrs):**
- Hiring-manager/founder outreach: ~8 hrs (research targets, write personalized messages, send)
- Targeted applications via ATS: ~4 hrs (only roles passing ticket 05 criteria)
- Recruiter responses + proactive recruiter contact: ~2 hrs

**Training (50% — ~17.5 hrs):**
- GPU fleet operator project (Python weeks 1–6, Go weeks 7–12): ~15 hrs
- Light conceptual study (distributed training, datacenter fabric): ~2.5 hrs (low-energy periods)

**Pipeline management + follow-up (10% — ~3.5 hrs):**
- Track all applications, outreach, and responses in a pipeline spreadsheet
- Send follow-ups (5–7 days, then 10–14 days)
- Weekly review: count applications sent, responses received, screens booked, rejections, and project milestones

### Phase-specific adjustments

**Phase 1 (weeks 1–6):**
- Weeks 1–2: 20% search / 70% training / 10% management (building assets and project foundation). CV restructure and LinkedIn update happen in week 1 before any outreach. Outreach starts week 2. GitHub repo link goes live as soon as the first commit exists.
- Weeks 3–6: 45% search / 45% training / 10% management (full outreach + active project). By end of week 3, basic operator skeleton runs on kind/k3d. By end of week 6, full Python operator + GPU testing + SLO layer + README.

**Phase 2 (weeks 7–12):**
- Weeks 7–9: 50% search / 40% training / 10% management (Go ramp-up, full search). By end of week 9, basic Go operator compiles and runs.
- Weeks 10–12: 55% search / 35% training / 10% management (search prioritizes as project nears completion). By end of week 12, Go port complete with improved logic and polished repo.

### Funnel signals to measure weekly

| Signal | What it tells you |
|---|---|
| Applications sent | Volume health |
| Outreach messages sent | Outreach volume |
| Response rate (outreach) | Whether targeting and messaging work |
| Screen rate (applications) | Whether role targeting and CV match |
| Screen-to-rejection ratio | Whether qualification is the bottleneck (per ticket 01) |
| Technical interviews reached | Whether qualification problem is closing |
| Compensation mismatches | Whether floors are calibrated per market |
| Project milestones hit | Whether training is on track |

### Adaptation thresholds

1. **Outreach response rate < 10% after 3 weeks (weeks 2–4):** Revisit targeting and messaging. Adjust one variable at a time.

2. **Screen-to-rejection ratio > 75% after 4 weeks (weeks 2–5):** Qualification problem persists. Re-examine which filter (relevance, readiness, compensation) is dominant. Adjust pre-qualification questions or narrow role bands.

3. **Zero technical interviews by week 6:** Pause new applications for one week. Audit every rejection for patterns. Check whether the Python evidence (now live on GitHub) changes the response rate — if not, the problem is targeting or positioning, not evidence.

4. **Compensation mismatches > 50% of rejections in a market:** Floor may be miscalibrated. Research actual compensation bands for mid-level SRE in that city and adjust.

5. **Project milestones slip by more than 1 week:** Reduce search time allocation by 10% temporarily. The evidence artifact is the highest-leverage asset — protect it.

6. **Switzerland response rate consistently lower than Berlin after 4 weeks:** Reallocate 10% of effort from Switzerland to Berlin. Revisit after another 3 weeks. Do not abandon Switzerland — rebalance.

7. **Bridge opportunity (Tier C) above €70k with AI exposure and architectural scope:** Pursue it. A bridge role that materially advances positioning and enables relocation is a stepping stone, not a failure.

### Weekly review ritual (Friday, 1 hour)

- Count all funnel signals for the week
- Note which adaptation thresholds (if any) were triggered
- Decide adjustments for next week
- Update the pipeline spreadsheet
- Set 3 priorities for next week (1 search, 1 training, 1 follow-up)
