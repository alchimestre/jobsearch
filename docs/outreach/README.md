## Rules

- **Applicant voice**, per `docs/writing-style.md`: no tool enumeration, no em dashes, no rhetorical
  contrasts, no invented metrics, one paragraph.
- **Connection notes: hard limit 300 characters.** LinkedIn truncates silently past that.
- **Follow-up messages: ≤120 words.** The Cohere follow-up is the one deliberate exception (125) because it
  is a follow-up rather than a cold note and must cover two requisitions.
- **When sent:** move the file to `sent/`, add the date and the channel, and move the issue to Stage
  `Contacted` (or comment if already there) with `channel:outreach`.
