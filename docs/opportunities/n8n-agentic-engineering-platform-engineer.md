## Tier caveat — AI dev-tooling, not ML-serving

Tier B is the AI-native-company / Berlin lane (§2 Admit 2). This role **does not own the ML/AI serving
platform**: it builds the paved road that autonomous coding agents run on inside n8n's own engineering
organisation — sandboxed execution environments, permission and secret boundaries, CI/Linear/GitHub
integration, agent-quality benchmarks, adoption metrics. That is genuinely **AI systems** work, but it is not
model serving, pipelines or registry. Logged as `track:ai` with the boundary stated so the funnel stays
interpretable: rank it below a real ML-platform role, above any Tier C bridge.
